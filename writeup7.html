Bugku source Writeup

题目信息

题目：POST，类型:Web，分数：10

场景中只存在几个没有信息的文字

解题过程

1. 访问靶场页面，发现存在 /.git/ 目录，存在Git源码泄露漏洞。

2. 使用GitHacker工具拉取仓库源码，命令：

githacker --url http://160.202.254.160:12786/git/ --output-folder bugku_source

⚠️ 协议必须是http，使用https会出现SSL版本错误。

3. 等待工具执行完毕，提示 exploited successfully 代表导出成功，进入仓库目录：

cd bugku_source\d8bfea8fc54f947ae682588ccdf5765

4. 当前目录flag.txt为假flag，使用git reflog查看全部操作记录：

git reflog

5. 使用git show + commit哈希，查看旧版本文件：

git show 40c6d51

6. 获取flag：flag{git_is_good_distributed_version_control_system}

知识点

  • Git泄露：网站上线未删除.git文件夹，可下载源码+全部历史版本
  • git reflog：记录所有仓库操作，找回被reset丢弃的提交
  • git show：查看某次提交的文件内容，找回被删除信息
